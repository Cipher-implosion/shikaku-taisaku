## 優先復習ドメイン（正答率順）

1. **ドメイン5: プロジェクト管理（33.3%）** — Issue のピン留め、Issues の既定フィルター、Projects の built-in workflow・view 機能など、GitHub Projects / Issues 管理系の基礎知識が弱い。
2. **ドメイン2: GitHub リポジトリの操作（42.9%）／ドメイン4: モダン開発（42.9%）** — gist、Insights、リポジトリ可視性、GitHub Actions・Copilot・Codespaces まわりの用語や仕組みの理解が不足。
3. **ドメイン6: プライバシー、セキュリティ、管理（54.5%）** — 2FA、Enterprise/Organization レベルの権限設定、internal repository の可視性ルールなど、管理者視点の設定が曖昧。
