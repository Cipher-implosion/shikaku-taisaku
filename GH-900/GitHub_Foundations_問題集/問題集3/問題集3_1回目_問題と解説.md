## 問題1
**新しい open source コントリビューターが GitHub Sponsors から資金援助を受けるには、どの状態になっている必要がありますか？**

- PayPal を支払い処理サービスとして使用する
- コントリビューション額の 95% に相当する
- GitHub のマッチング資金を含める

**解説**
GitHub Sponsors で資金を受け取るには、スポンサー付き開発者プロフィール（sponsored developer profile）を設定し、スポンサーを受け付けられる状態にする必要があります。PayPal、95% という比率、GitHub matching funds は、この設問の条件ではありません。

参照: [個人アカウントのGitHubスポンサーを設定する - GitHubドキュメント](https://docs.github.com/ja/sponsors/receiving-sponsorships-through-github-sponsors/setting-up-github-sponsors-for-your-user-account)

## 問題2
**Enterprise レベルで有効化または無効化できる権限は次のうちどれですか？（2つ選択）**

- repository secrets
- リポジトリ名の命名規則
- リポジトリの削除と転送 ✅（正解）

**解説**

## 問題5
**Organization owner が自組織内の全メンバーに 2 要素認証 (2FA) を必須化するには、どの設定を有効にする必要がありますか？**

- Organization Settings の Authentication security で「Require two-factor authentication」を有効化する ✅（正解）
- Organization Settings の Repository Rules で 2FA を必須にするルールを追加する
- Organization Settings の Member privileges で MFA を有効化する
- Enterprise Settings の Policies で組織単位の 2FA を強制する

**解説**
Organization Settings の Authentication security で「Require two-factor authentication for everyone in your organization」を有効化すると、組織内メンバー全員に 2FA が必須化されます。2FA を設定していないメンバーと請求管理者は 2FA を有効にするまで Organization のリソースへアクセスできず、2FA を設定していない外部コラボレーターは Organization から削除されるため、有効化前に告知が推奨されます。

参照: [Organization で 2 要素認証を要求する - GitHubドキュメント](https://docs.github.com/ja/organizations/keeping-your-organization-secure/managing-two-factor-authentication-for-your-organization/requiring-two-factor-authentication-in-your-organization)

## 問題6
**Git remote とは何ですか？**

- 別の場所にホストされているリポジトリへの参照 ✅（正解）

## 問題10
**commit は pull request とどのように関係しますか？**

- commit は、リンクされた pull request を持つことができるブランチ上で作成される ✅（正解）
- commit は pull request が作られた後の段階でしか作成できない
- pull request を用意する前にしか、commit を追加することはできない
- commit は、リンクされたブランチを持つことができる pull request 上で作成される

**解説**

参照: [GitHub フロー - GitHubドキュメント](https://docs.github.com/ja/get-started/using-github/github-flow)

- Git はクラウドベースのホスティングサービスで、GitHub は分散バージョン管理システムである
- Git はファイル変更を追跡するコマンドラインツールで、GitHub は Git リポジトリ上で共同作業するためのプラットフォームである ✅（正解）

## 問題25
**README ファイルが複数ある場合、最初に表示される場所は次のうちどれですか？**

- .github ✅（正解）
- /src
- Root
- /docs

**解説**
複数の README があるリポジトリでは、GitHub は .github ディレクトリ、リポジトリの root、docs ディレクトリの順（.github > root > docs）で最初に見つかった README をリポジトリトップで表示します。root は 2 番目、/docs は 3 番目の候補で、/src は優先候補には含まれません。

参照: [リポジトリの README ファイルについて - GitHubドキュメント](https://docs.github.com/ja/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-readmes)
