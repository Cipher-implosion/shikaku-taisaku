## 優先復習ドメイン（正答率順）

1. **ドメイン4: モダン開発（36.8%）** — dev container・Codespaces のパーソナライズ項目、Codespace の再開手順、GitHub Actions の action 参照元など、モダン開発ツール群の細かい仕様の理解が不足。
2. **ドメイン3: コラボレーション機能（50.0%）／ドメイン5: プロジェクト管理（50.0%）／ドメイン6: プライバシー、セキュリティ、管理（50.0%）** — Markdown構文・Issueテンプレートの配置場所・GitHub Mobileの機能範囲・conversationの自動subscribe条件・Projects Classicとの差分・Securityタブのアラート種別など、機能の細部を問う設問で失点しやすい。
3. **ドメイン2: GitHub リポジトリの操作（52.6%）** — リポジトリの発見性向上（README・topics）など一部の設問でまだ取りこぼしがある。
