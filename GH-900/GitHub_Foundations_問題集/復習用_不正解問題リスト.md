# GH-900: 復習用 不正解問題リスト（問題集①〜④ 1回目）

不正解だった問題のみを、正答率が低いドメイン順に並べています。各項目の詳しい解説は出典元の「問題と解説」ファイルを参照してください。

- 合計不正解数: 49問（全99問中）

---

## ドメイン4: モダン開発（7／19, 36.8%）— 最優先復習

1. **[問題集①-Q2]** GitHub 承認済みベンダーの既存 action を見つける方法は？（2択）
   → 正解: **action に verification badge があるか確認する／GitHub Marketplace でベンダーの Actions を検索する**
2. **[問題集①-Q5]** Codespaces を個人向けにパーソナライズする仕組みは？（2択）
   → 正解: **dotfiles／Settings Sync**
3. **[問題集①-Q14]** GitHub がホストされたランナーを提供している対象は？
   → 正解: **Linux、Windows、macOS**
4. **[問題集①-Q23]** GitHub Copilot が活用する AI モデルは何でトレーニングされているか？
   → 正解: **public GitHub リポジトリ**
5. **[問題集②-Q13]** GitHub Actions の構成要素は？（3択）
   → 正解: **events／steps／jobs**
6. **[問題集③-Q4]** GitHub Copilot を最もよく表す説明は？
   → 正解: **autocomplete 形式の提案を行う AI ペアプログラマー**
7. **[問題集③-Q13]** 対応する IDE で GitHub Copilot を使用する手順は？（2択）
   → 正解: **Copilot 拡張機能をインストールする／エディションにサインアップし有効にする**
8. **[問題集③-Q23]** workflow から参照できる action の配置場所は？（3択）
   → 正解: **任意の public repository／workflow ファイルと同じリポジトリ／Docker Hub 上の公開 Docker コンテナーイメージ**
9. **[問題集④-Q8]** Codespace の開発環境を構成・パーソナライズできるものは？（3択）
   → 正解: **dotfiles を使ったシェル設定やスクリプト／extensions や plugins／プロジェクトに必要なプログラミング言語やツール**
10. **[問題集④-Q11]** 既存の Codespace を再開する方法は？（2択）
    → 正解: **GitHub.com でリポジトリを開き comma+V キーで Resume this codespace を選択／https://github.com/codespaces から既存の Codespace を選択**
11. **[問題集④-Q13]** Codespaces の利用環境や開き方でカスタマイズできる項目は？（3択）
    → 正解: **Shell／Name／Default editor**
12. **[問題集④-Q19]** workflows が参照できる action の場所は？（3択）
    → 正解: **任意の public repository／workflow ファイルと同じリポジトリ／Docker Hub 上で公開された Docker container image**

## ドメイン3: コラボレーション機能（9／18, 50.0%）

1. **[問題集①-Q8]** conversation に自動的にサブスクライブされる操作は？（3択）
   → 正解: **@mention される／Pull Request を開く／コメントする**
2. **[問題集①-Q11]** GitHub Mobile で利用できる機能は？（3択）
   → 正解: **画像比較レビュー／通知の管理・トリアージ・クリア／push 通知のカスタム時間設定**
3. **[問題集①-Q20]** Organization 内で条件付き Issue を検索する最適な手順は？
   → 正解: **`org:Avocado is:issue label:guacamole "404 error"`**
4. **[問題集③-Q15]** pull request の有効なステータスは？（4択）
   → 正解: **Draft／Closed／Merged／Open**
5. **[問題集③-Q16]** pull request を作成できるのはどのような 2 つのブランチ間か？
   → 正解: **異なるブランチ**
6. **[問題集④-Q1]** GitHub 構文形式で対応するテキストと一致するものは？
   → 正解: **HTML コメントの開始・終了記号で This is a comment を囲む**
7. **[問題集④-Q10]** custom issue forms の定義ファイルを保存するフォルダーは？
   → 正解: **.github/ISSUE_TEMPLATE**
8. **[問題集④-Q14]** GitHub Mobile 内で実行できることは？
   → 正解: **github.com からの通知を管理する**
9. **[問題集④-Q17]** conversations に自動的に subscribe されるシナリオは？（3択）
   → 正解: **Pull Request または Issue を開く／スレッドにコメントする／Issue または Pull Request に割り当てられる**

## ドメイン5: プロジェクト管理（5／10, 50.0%）

1. **[問題集②-Q4]** Issues ページの上部に Issue を表示して見つけやすくする機能は？
   → 正解: **Issue をピン留めする**
2. **[問題集②-Q6]** 高度な検索構文を使わず Issue を検索するとき、既定で使えるフィルターは？（2択）
   → 正解: **自分に割り当てられているもの／自分の Issue**
3. **[問題集②-Q15]** GitHub Projects でプロジェクト初期化時に既定で有効な workflow は？（2択）
   → 正解: **Pull Request がマージされたとき／アイテムがクローズされたとき**
4. **[問題集③-Q24]** GitHub Projects の主要な特徴は？
   → 正解: **複数の view を作成してカスタマイズできる**
5. **[問題集④-Q16]** GitHub Projects が Projects Classic より優れている点は？（2択）
   → 正解: **複数の layout views がある／Insights がある**

## ドメイン6: プライバシー、セキュリティ、管理（7／14, 50.0%）

1. **[問題集①-Q19]** GitHub アカウントを保護できる 2 要素認証 (2FA) の方法は？（3択）
   → 正解: **認証アプリ／GitHub Mobile／セキュリティキー**
2. **[問題集①-Q22]** Organization owner が設定できる GitHub Actions の利用制限は？（3択）
   → 正解: **指定した action を許可する／Marketplace verified creator による action を許可する／GitHub が作成した action を許可する**
3. **[問題集②-Q16]** base permission が No permissions のとき、internal repository を閲覧できるユーザーは？（2択）
   → 正解: **同じ organization のメンバー／その Enterprise 内の別 organization に所属するメンバー**
4. **[問題集③-Q2]** Enterprise レベルで有効化・無効化できる権限は？（2択）
   → 正解: **リポジトリの削除と転送／リポジトリの可視性変更**
5. **[問題集③-Q14]** GitHub Team が GitHub Free より優れている理由は？
   → 正解: **増加した GitHub Actions 分数と追加の GitHub Packages ストレージ**
6. **[問題集④-Q2]** UI のどこで two-factor authentication (2FA) を設定できるか？
   → 正解: **Settings -> Password and Authentication -> 2FA**
7. **[問題集④-Q15]** リポジトリの Security タブで確認できるアラートは？（3択）
   → 正解: **Dependabot／Code Scanning／Secret Scanning**

## ドメイン2: GitHub リポジトリの操作（10／19, 52.6%）

1. **[問題集①-Q1]** secret gist を最も正確に説明している記述は？
   → 正解: **gist の URL を知っている人なら誰でも表示できる**
2. **[問題集①-Q9]** PR、Issue、コミット履歴などを表示できる Insights の機能は？
   → 正解: **Pulse**
3. **[問題集①-Q13]** GitHub Enterprise で使用できるリポジトリの可視性オプションは？
   → 正解: **public、internal、private**
4. **[問題集①-Q16]** GitHub における gist とは何か？
   → 正解: **Git リポジトリ**
5. **[問題集②-Q18]** リポジトリ内の複数ファイルをすばやく変更するのに最適なツールは？
   → 正解: **ブラウザから github.dev を使う**
6. **[問題集③-Q8]** リポジトリテンプレートを作成できる権限は？
   → 正解: **Admin ロールで Repository Settings を開き、Template Repository を ON にする**
7. **[問題集③-Q10]** commit は pull request とどのように関係するか？
   → 正解: **commit は、リンクされた pull request を持つことができるブランチ上で作成される**
8. **[問題集③-Q25]** README ファイルが複数ある場合、最初に表示される場所は？
   → 正解: **.github**（優先順位: .github > root > docs）
9. **[問題集④-Q4]** リポジトリを見つけやすくするために推奨される方法は？（2択）
   → 正解: **README ファイルを作成する／topics を追加する**

## ドメイン1: GitHub 入門（6／9, 66.7%）

   → 正解: **ローカルファイル操作とオフライン作業**
